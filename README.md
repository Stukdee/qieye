# 切页 SPLIT

一个单文件、纯前端的图片等分切片工具，适合把一张图切成多条后分图发布。

## 使用

1. 直接双击 `index.html`，用 Chrome、Edge、Safari 或 Firefox 打开。
2. 上传 PNG / JPG / WebP 图片（也可以拖拽或直接 `⌘V` 粘贴）。
3. 输入切分数量（2–20），选择横向或纵向切分。
4. 点击「生成并下载 ZIP」。

所有处理都在浏览器本地完成，图片不会被上传。切片保持原始像素尺寸，输出无损 PNG；遇到不能整除的宽度或高度时，每张相差不超过 1px。ZIP 内的文件按 `01-of-N` 顺序编号。

## 文件

- `index.html`：完整的网页应用，无需安装依赖，无需联网。
